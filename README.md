# 📚 Plateforme de Gestion des Inscriptions

Projet développé dans le cadre du cycle d’ingénieur TICSE à l’Université Privée de Marrakech.

## 🗂️ Description

Cette application web permet de *centraliser, **sécuriser* et *simplifier* le processus d’inscription au sein d’une organisation.
Elle propose :
- Une interface utilisateur réactive avec *React.js*
- Un backend robuste avec *Node.js & Express*
- Une base de données *MongoDB*
- Des fonctionnalités de sécurité avancées (authentification, rôles, journalisation)

## ✨ Fonctionnalités principales

- Authentification et contrôle d’accès par rôle
- Gestion hiérarchique des inscriptions
- Tableau de bord et statistiques en temps réel
- Structure géographique (région, province, commune)
- API REST sécurisée

## 🔧 Stack technique

- *Frontend* : React.js, CSS3
- *Backend* : Node.js, Express.js
- *Base de données* : MongoDB (avec Mongoose)
- *Outils* : VS Code, Git, GitHub, Postman, StarUML
